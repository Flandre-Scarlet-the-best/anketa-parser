# Codex

Codex can discover repository skills under `.agents/skills`; confirm the current
session catalog and load the skill when applicable. Serena is a separately
configured MCP server, not a built-in or guaranteed dependency. Discover the
available tools and read its session instructions before use. Verify its active
project points to this worktree and its language server and index cover the files.
Use supported symbol, reference, implementation and diagnostic operations as
needed; check the live schemas and responses. Other MCP configurations may expose
other operations. If unavailable or scoped elsewhere, use the common fallback and
state the limit. See [Serena documentation](https://oraios.github.io/serena/02-usage/020_running.html).
