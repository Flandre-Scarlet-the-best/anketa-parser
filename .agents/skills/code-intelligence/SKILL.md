# Code intelligence

Determine the current worktree, language and change scope; discover the tools
and capabilities actually available there. Use search and read for ordinary file
and text navigation. For semantic relationships and risky changes consult
[semantic navigation](references/semantic-navigation.md). After edits consult
[diagnostics](references/diagnostics.md) when relevant, and select checks using
[verification tools](references/verification-tools.md). Load only the applicable
harness reference: [Codex](references/harnesses/codex.md),
[DSH](references/harnesses/dsh.md), or [Claude Code](references/harnesses/claude-code.md).
Report tool failures, coverage and fallback limitations accurately.
