# Документация anketa-parser

Здесь описана работающая инфраструктурная основа на C#/.NET 10. Начните с
[быстрого старта](../README.md), затем выберите задачу.

| Задача | Руководство |
| --- | --- |
| Понять устройство и границы проекта | [Архитектура](architecture.md) |
| Запустить диагностику, прочитать JSON и код выхода | [CLI и готовность](diagnostics.md) |
| Настроить сбор одного треда и проверить отбор сообщений | [Двач](dvach.md) |
| Настроить LLM Worker и проверить результаты | [Текстовый анализ](llm.md) |
| Изменить настройки и найти источник значения | [Конфигурация](configuration.md) |
| Запустить хост и PostgreSQL, остановить их, разобраться с ошибкой | [Эксплуатация](operations.md) |
| Собрать проект и выбрать проверки | [Разработка](development.md) |
| Понять обращение с секретами и текущие ограничения | [Безопасность](security.md) |

Эти страницы — канонические объяснения продукта для людей. Код, конфигурация,
тесты и CI определяют фактическое поведение. README содержит только знакомство и
минимальный старт. [AGENTS.md](../AGENTS.md) задаёт обязательные правила агента;
[контекст](../.codex/context/INDEX.md) помогает любому агенту найти владельца
кода и проверок. Процедуры Git и CodeRabbit принадлежат
[существующим skills](../.agents/skills/), а не документации продукта.

Команды выполняются из корня репозитория. Ожидаемые результаты в руководствах —
ориентиры для воспроизведения, а не журнал выполненной приёмки конкретного коммита.

[Хранилище, миграции и резервирование](persistence.md) — модель, права, переход существующей БД и восстановление.
